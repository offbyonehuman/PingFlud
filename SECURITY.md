# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability-reporting feature for this repository when it is available. If private reporting is unavailable, contact the repository owner, **OffByOneHuman**, through GitHub and request a private reporting channel.

Include:

- affected Ping Flud version and Windows architecture;
- concise reproduction steps or a proof of concept;
- expected and actual behavior;
- potential impact; and
- any mitigation you have already identified.

Do not include real private-network addresses, credentials, tokens, or customer data.

## Supported versions

Security fixes are provided for the latest published release.
